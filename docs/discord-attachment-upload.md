# Discord attachment upload for workers

Use the repository CLI when a user explicitly asks for generated files to be attached to the current Discord thread. It uses the inherited `DISCORD_BOT_TOKEN`; never print, persist, or pass that token on the command line.

```bash
node scripts/discord-upload.mjs \
  --channel "$DISCORD_THREAD_ID" \
  --content "수정본 5장입니다." \
  artifacts/slide-01.png artifacts/slide-02.png
```

If `DISCORD_THREAD_ID` is not present, use the thread ID supplied in the bridge prompt. Do not guess a destination and do not upload to a parent channel when the user requested the thread.

The CLI:

- splits more than 10 files into legal Discord batches;
- retries Discord HTTP 429 responses;
- re-reads every created Discord message;
- downloads every attachment and compares byte size and SHA-256 with the local source;
- exits non-zero if an upload or verification step fails.

The JSON result contains the Discord message IDs and verified hashes. Report completion only after the command exits successfully.

## Required visual/content check

Transport verification proves that Discord stored the same bytes; it does **not** prove that an image is meaningful. Before upload, inspect every image (or every page rendered from a PDF) with the available image/PDF viewer. Reject blank pages, placeholder grids, missing photos, clipped text, tofu glyphs, and accidental monochrome output. For a contact sheet, verify the requested number of populated cells rather than checking dimensions alone.

After upload, use both checks:

1. visual/content inspection before upload;
2. Discord re-read plus downloaded SHA-256 verification by the CLI.

For Korean labels generated by Python, use the bridge-provided font rather than
the host's default font. The worker environment exposes the regular TTF at
`BRIDGE_KOREAN_FONT_FILE`; pass it to `matplotlib.font_manager.FontProperties`
or `PIL.ImageFont.truetype` and inspect the resulting PNG for tofu boxes before
uploading it.

`--no-verify` exists only for diagnostics. Do not use it when the user asked to confirm that the files arrived correctly.
